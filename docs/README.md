## Current Direction

StockPilot is being redirected from a generic POS/inventory dashboard and from the earlier utang-only pivot into **StockPilot Counter AI**:

> A tablet-first, offline-capable AI counter system for serious small retailers that tracks sales, stock, cash, supplier purchases, and customer credit.

The earlier [ROADMAP.md](./ROADMAP.md) is useful historical context, especially for the utang schema work already started, but it is no longer the primary product plan.
